# Personal Developer Profile & Portfolio Website

## Design

The website uses a modern and professional developer-focused design.

### Colour Scheme

The main colours used are:

* Dark navy for the main background
* Darker navy for some sections and the footer
* Light blue for headings, buttons and highlights
* White/light grey for readable text

The dark background gives the website a professional technology-focused appearance, while the blue accent colour helps important elements stand out.

### Layout

The website uses separate sections for different types of information.

The main structure is:

```text
Navigation
    ↓
Home
    ↓
About
    ↓
Skills
    ↓
Projects
    ↓
Journey
    ↓
Contact
    ↓
Footer
```

The website uses Flexbox and CSS Grid to arrange content and cards.

### Typography

Arial is used as the main font because it is simple, clean and easy to read across different devices.

---

## Responsive Design

The website is designed to work on different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

CSS media queries are used to adjust the layout for smaller screens.

For example, the skills cards change from multiple columns to a single-column layout on smaller screens.

The navigation and Home section are also adjusted for mobile devices.

## How to Run the Website

No special software or server is required to run this website.

### Option 1: Open Directly in a Browser

1. Download or clone the project repository.
2. Open the project folder.
3. Locate `index.html`.
4. Double-click `index.html`.
5. The website will open in your default web browser.

### Option 2: Using Visual Studio Code

1. Open Visual Studio Code.
2. Select **File → Open Folder**.
3. Select the `personal-developer-portfolio` folder.
4. Open `index.html`.
5. Open the file in a web browser.

If the Live Server extension is installed, `index.html` can also be opened using Live Server.
